# Prompt Modules

This folder is the "prompt module registry" for `memory/prompt_layout.json`.

Goal: make each prompt part have an explicit, separately managed source of truth:
- static modules: maintained as standalone files under `memory/prompt_modules/`
- dynamic modules: generated at runtime under `runs/<run_name>/memory/` (or `memory_dir`)

## Sections And Their Sources

SYSTEM sections (configured by `prompt_layout.json.system_sections`):
- `system_role`: `memory/prompt_modules/system_role.txt` (static)
- `body_rules`: `memory/body_rules.txt` (static, filtered to remove legacy capabilities block)
- `strategy_notes`: `memory/strategy_notes.txt` (static planning guidance / heuristics)
- `reflexion_memory`: `memory_dir/reflexion_memory.txt` (runtime, may be seeded from `memory/reflexion_memory.txt`)
- `tools_manifest_openai`: `memory/tools_manifest_openai.json` (static, rendered into readable schemas)
- `skill_cards`: `memory_dir/skills_catalog.json` + `memory_dir/action_specs.txt` (+ optional `memory_dir/parameter_heuristics.json`) (runtime generated)
- `skill_specs`: `memory_dir/skill_specs.txt` (runtime generated)

USER sections (configured by `prompt_layout.json.user_sections`):
- `goal`: generated by the agent (current high-level goal id + goal text)
- `recipe_text`: generated by the agent (dish recipe text)
- `observation`: generated by the agent (with `observation_mode=image_only`, prompt only says an image is provided)
- `agent_state`: `memory_dir/agent_state.json` (runtime)
- `feedback`: generated by the agent (last-step feedback)
- `stm_window`: `memory_dir/stm_window.txt` (runtime)
- `percept_text`: generated by perception module (optional, controlled by `prompt_policy.include_percept`)
- `task_progress`: `memory_dir/task_progress.txt` (runtime, optional, controlled by `prompt_policy.include_task_progress`)
